Report DWG / DXF file version
=============================

Outputs a version of a DWG / DXF file.

Inputs:

* Source file. Source file in AutoCAD DWG or DXF format

Outputs:

* Information about software version in text format.

Launch the tool: https://toolbox.nextgis.com/t/autocad_version

Example output::

   Magic: DWG AutoDesk AutoCAD 2007/2008/2009
   MIME: image/vnd.dwg
   DWG code: AC1021
   DWG version: DWG 2007/2008/2009




**Try the tool in action**

1. Click on the **Demo** button above the tool form. The fields are filled in with demo values.
2. Click on the **Run** button.
