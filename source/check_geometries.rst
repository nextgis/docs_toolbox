Проверка геометрии

==================

Проверка векторного файла на корректность геометрий. На выходе CSV файл со списком ошибок и координат и GeoJSON файл с геометриями месторасположения ошибок

На входе:

* ZIP-архив c векторными файлами. ZIP-архив должен быть устроен таким образом: файлы форматов, состоящих из одного файла (например, GeoJSON), должны быть в виде самого файла. файлы форматов, состоящих из нескольких файлов (например, ESRI Shapefile) должны быть в виде ZIP-архива

На выходе:

* Файл CSV со списком ошибок
* Файл GeoJSON, в котором точками отмечены места ошибок

Запуск инструмента: https://toolbox.nextgis.com/t/check_geometries
