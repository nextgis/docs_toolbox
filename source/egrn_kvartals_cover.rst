Список КПТ/КВЗУ по заданной области
==============================

Инструмент позволяет получить документ с перечнем кадастровых номеров кварталов или земельных участков, которые попали в заданную полигоном область.

На входе:

* Область интереса - полигон в формате GeoJSON площадью не более 50 км². Система координат - WGS84 (EPSG:4326). 
* Режим - позволяет выбрать, информацию по каким кадастровым единицам необходимо получить. Укажите "кпт"/"kpt" для формирования перечня кадастровых номеров кварталов, "квзу"/"kvzu" - для формирования перечня земельных участков.

На выходе:

* Файл CSV с кадастровыми номерами кварталов.

Запуск инструмента: https://toolbox.nextgis.com/t/egrn_kvartals_cover

**Попробуйте инструмент в действии, скачав наш пример:**

`Набор исходных данных <https://nextgis.ru/data/toolbox/egrn_kvartals_cover/egrn_kvartals_cover_inputs_ru.zip>`_ для проверки работы инструмента. Внутри архива пошаговая инструкция.
