EGRN Splitter
=============

Split extra large EGRN extracts into layes of smaller size, reducing the volumes for futher conversion.

Inputs:

* Input extract. Select input extract ZIP file.

Outputs:

* None

Launch the tool: https://toolbox.nextgis.com/t/egrn_splitter




**Try the tool in action**

1. Click on the **Demo** button above the tool form. The fields are filled in with demo values.
2. Click on the **Run** button.
