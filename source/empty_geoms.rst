Empty geometries in Web GIS layer
=================================

Find and remove empty geometries in a Web GIS layer.

Inputs:

* Web GIS address. URL of your Web GIS, e.g. https://sandbox.nextgis.com;
* ID of the vector layer. Numbers at the end of the URL of the vector layer resource in Web GIS;
* Login. NextGIS ID or Web GIS username;
* Password. Web GIS user password;
* Remove. Tick to remove empty geometry features from Web GIS layer.

Outputs:

* Result. A list of empty geometry features IDs.


Launch the tool: https://toolbox.nextgis.com/t/empty_geoms
