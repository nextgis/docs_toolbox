Пустые геометрии в слое Веб ГИС
===============================

Находит и удаляет объекты с пустыми геометриями в слое Веб ГИС.

На входе:

* Адрес Веб ГИС. Ссылка на Веб ГИС на платформе NextGIS вида https://sandbox.nextgis.com;
* ID векторного слоя в Веб ГИС. Цифры в конце URL существующего векторного слоя Веб ГИС;
* NextGIS ID или Логин. Имя пользователя Веб ГИС с `правами чтения <https://docs.nextgis.ru/docs_ngcom/source/permissions.html>`_ (в случае удаления объектов нужно также право на изменение данных);
* Пароль. Пароль пользователя Веб ГИС;
* Удалить. Отметьте, чтобы удалить объекты с пустыми геометриями из ресурса Веб ГИС.

На выходе:

* Текстовый файл: список ID объектов с пустой геометрией

Запуск инструмента: https://toolbox.nextgis.com/t/empty_geoms



**Попробуйте инструмент в действии, скачав наш пример:**

`Набор исходных данных <https://nextgis.ru/data/toolbox/empty_geoms/empty_geoms_inputs_ru.zip>`_ для проверки работы инструмента. Внутри архива пошаговая инструкция.

`Пример результата <https://nextgis.ru/data/toolbox/empty_geoms/empty_geoms_outputs_ru.zip>`_ работы инструмента.
