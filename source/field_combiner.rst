Комбинированное поле
====================

Запись в целевое поле нового значения, составленного из нескольких других полей.

На входе:

* Адрес Веб ГИС. Ссылка на Веб ГИС на платформе NextGIS Web вида https://demo.nextgis.com и логин/пароль если необходимо;
* ID слоя. Цифры в конце ссылки на ресурс векторного слоя;
* Исходное поле 1. Строковое поле, в котором записана первая часть, например, 'id_prefix';
* Исходное поле 2. Поле, в котором записана первая часть, может быть числовым или датой, например, 'id_date';
* Исходное поле 3. Строковое поле, в котором записана первая часть, например, 'id_suffix'.
* Целевое поле. Атрибут, в который будет записываться составное значение, например, 'id_combined';
* Название запуска. Пользовательское название запуска (не обязательно), например "Обновить слой проб".

На выходе:

* Обновлённый векторный слой в Веб ГИС.

Запуск инструмента: https://toolbox.nextgis.com/t/field_combiner
