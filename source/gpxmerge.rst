

Объединение GPX файлов 
========================

Объединяет GPS треки в формате GPX в один. Большинство программ открывает треки по одному, но благодаря этому инструменту нет необходимости выяснять, в какую дату был записан трек нужного места, можно открыть все собранные данные сразу.

.. figure:: _static/gpxmerge_output_ru_2.png
   :name: gpxmerge_output_pic
   :align: center
   :width: 20cm

   Множество треков единым слоем на карте

Кроме того, инструмент позволяет починить файлы GPX, повреждённые при при выключении питания.


На входе: 

* ZIP архив с GPX файлами. В архиве могут быть многократно вложенные папки. Файлы в разных папках внутри архива могут называться одинаково, инструмент их примет.
* Режим - выберите из списка:

   * **Точный** - соединяет всё содержимое файлов используя gpsbabel. Если файлов много, то будет работать медленно. 
   * **Быстрый** - соединяет содержимое тегов <gpx> как текстовые файлы. Быстро, не сохраняет GPX Extensions, данные упрощаются.


.. important::
	Архивы внутри архива не поддерживаются. 



На выходе: 

* Объединённый файл GPX;
* Список пропущенных/неверных файлов (если есть).

Запуск инструмента: https://toolbox.nextgis.com/t/gpxmerge

**Попробуйте инструмент в действии**

1. Нажмите кнопку **Демо** над формой инструмента. Поля будут автоматически заполнены демонстрационными значениями.
2. Нажмите кнопку **Запустить**.
