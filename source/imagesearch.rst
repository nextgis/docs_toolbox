Поиск снимков Sentinel через Copernicus
========================================

Инструмент формирует перечень сцен Sentinel в архиве Copernicus, соответствующих заданным критериям.

Формирование перечня сцен Sentinel из архива Copernicus, соответствующих заданным критериям.

На входе:

* Область поиска снимков - рекомендуется формат GeoJSON СК 4326. Поддерживаются однофайловые OGR совместимые форматы с информацией об СК. Файл должен содержать строго один объект. Типы геометрии: точка, линия, полигон (допускаются мульти-типы). Рекомендуется упрощать геометрию (не использовать большое количество вершин) или преобразовывать ее в охват.
* Начальная дата запрашиваемого интервала съёмки в формате UTC (снимки за эту дату **включаются** в результат поиска). Если оставить поле пустым - будет использована дата начала текущего месяца.
* Конечная дата запрашиваемого интервала съёмки в формате UTC (снимки за эту дату **не включается** в результат поиска). Если оставить поле пустым - будет использована текущая дата.
* Семейство спутников. Укажите семейство спутников (коллекцию):

  - Sentinel-2 (Sentinel-2)
  - Sentinel-1 (Sentinel-1)
  - Sentinel-3 (Sentinel-3)

* Продукты. По умолчанию поиск идёт по всем, можно вписать один или несколько из списка для соответствующего семейства спутников:

  - для Sentinel-2 ``S2MSI1C, S2MSI2A`` ;
  - для Sentinel-1 ``RAW, SLC, GRD, OCN`` ;
  - для Sentinel-3 ``OL_1_EFR___, OL_1_ERR___, OL_2_LFR___, OL_2_LRR___, OL_2_WFR___, OL_2_WRR___, SL_1_RBT___, SL_2_AOD___, SL_2_FRP___, SL_2_LST___, SL_2_WST___, SR_1_SRA___, SR_1_SRA_A_, SR_2_LAN___, SR_2_WAT___, SY_2_AOD___, SY_2_SYN___, SY_2_V10___, SY_2_VG1___, SY_2_VGP___``.

* Режим съемки. В случае Sentinel-2 или Sentinel-3 оставьте это поле пустым. В случае Sentinel-1, по умолчанию - все режимы. Можно указать один из предложенных:

  - Stripmap (SM)
  - Interferometric Wide Swath (IW)
  - Extra Wide Swath (EW)
  - Wave (WV)

* Облачность (максимум). Применимо только для Sentinel-2. Максимальная облачность в процентах. По умолчанию - 100%.


На выходе:

* Файл XLSX со списком идентификаторов сцен.
* Текстовый отчёт, показывающий общее количество найденных сцен и первые 10 идентификаторов.

Запуск инструмента: https://toolbox.nextgis.com/t/imagesearch

**Попробуйте инструмент в действии**

1. Нажмите кнопку **Демо** над формой инструмента. Поля будут автоматически заполнены демонстрационными значениями.
2. Нажмите кнопку **Запустить**.
