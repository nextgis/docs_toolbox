Поиск снимков Sentinel через Copernicus
========================================

Инструмент формирует перечень сцен Sentinel в архиве Copernicus, соответствующих заданным критериям.


* Область поиска снимков
Выберите файл или перетащите в эту область
Файл GeoJSON с одним полигоном, охватывающим желаемую территорию
Начальная дата
Начальная дата запрашиваемого интервала съемки, укажите в формате дд.мм.гггг
Конечная дата
Конечная дата запрашиваемого интервала съемки, укажите в формате дд.мм.гггг
* Имя сервиса
Имя сервиса, предоставляющего данные. Укажите copernicus
* Логин пользователя сервиса
Укажите ваш логин для сайта https://scihub.copernicus.eu
* Пароль пользователя сервиса
Укажите ваш пароль для сайта https://scihub.copernicus.eu
* Семейство спутников
Укажите один из
Sentinel-1
Sentinel-2
Sentinel-3
Тип продукта
Для Sentinel-1 выберите из: SLC, GRD, OCN, RAW. Для Sentinel-2 выберите из: S2MSI1C, S2MSI2A, S2MSI2Ap
Режим поляризации
Применимо только для Sentinel-1, укажите один из: HH, VV, HV, VH, HH+HV, VV+VH. В случае Sentinel-2 оставьте это поле пустым
Режим съемки
Применимо только для Sentinel-1, укажите один из: SM, IW, EW, WV. В случае Sentinel-2 оставьте это поле пустым
Облачность
Применимо только для Sentinel-2, укажите приемлемый уровень облачности в процентах, обозначив нижнюю и верхнюю границу через запятую с пробелом. Например, 0, 20
