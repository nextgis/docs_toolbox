Поиск снимков Sentinel через Copernicus
========================================

Инструмент формирует перечень сцен Sentinel в архиве Copernicus, соответствующих заданным критериям.

На входе:

* **Область поиска снимков** ``Обязательное поле`` - Файл GeoJSON с одним полигоном, охватывающим желаемую территорию;
* **Начальная дата** запрашиваемого интервала съемки, выберите в календаре или впишите в формате *гггг-мм-дд*;
* **Конечная дата** запрашиваемого интервала съемки,  выберите в календаре или впишите в формате *гггг-мм-дд*;
* **Логин пользователя сервиса** ``Обязательное поле`` - ваш логин для сайта https://dataspace.copernicus.eu;
* **Пароль пользователя сервиса** ``Обязательное поле`` - ваш пароль для сайта https://dataspace.copernicus.eu;
* **Семейство спутников** ``Обязательное поле`` - Укажите один из вариантов: ``Sentinel-1``, ``Sentinel-2``, ``Sentinel-3``;
* **Тип продукта** - зависит от выбранного семейства спутников:

  * Для Sentinel-1 выберите из: ``RAW``, ``SLC``, ``GRD``, ``OCN``; 
  * Для Sentinel-2 выберите из: ``RAW``, ``S2MSI1C``, ``S2MSI2A``, ``S2MSI2Ap``;
  * Для Sentinel-3 выберите из: ``RAW``, ``OL_1_EFR___``, ``OL_1_ERR___``, ``SR_1_SRA___``, ``SR_1_SRA_A_``, ``SR_1_SRA_BS``, ``SR_2_LAN___``, ``SL_1_RBT___``, ``SL_2_LST___``, ``SY_2_SYN___``, ``SY_2_V10___``, ``SY_2_VG1___``, ``SY_2_VGP___``, ``OL_2_LFR___``, ``OL_2_LRR___``;

* **Режим поляризации** - Применимо только для Sentinel-1, укажите один из: ``HH, VV, HV, VH, HH+HV, VV+VH``. В случае Sentinel-2 оставьте это поле пустым;
* **Режим съемки** - Применимо только для Sentinel-1, укажите один из: ``SM, IW, EW, WV``. В случае Sentinel-2 оставьте это поле пустым;
* **Облачность** - Применимо только для Sentinel-2, укажите приемлемый уровень облачности в процентах, обозначив нижнюю и верхнюю границу через запятую с пробелом. Например, ``0, 20``.

На выходе:

* Файл XLSX со списком идентификаторов сцен.

Запуск инструмента: https://toolbox.nextgis.com/t/imagesearch

**Попробуйте инструмент в действии**

1. Нажмите кнопку **Демо** над формой инструмента. Поля будут автоматически заполнены демонстрационными значениями.
2. Нажмите кнопку **Запустить**.
