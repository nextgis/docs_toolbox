GLR data converter 
===================

Convert National Forest Registy XML file to geodata.

Input:

* single XML file

Output:

* GPKG file

If the SRS of the input data is other than EPSG:4326, you'll need to select it manually in QGIS. After that the layer can be display in the project.

Launch tool: https://toolbox.nextgis.com/operation/import_glr

**Try it out using our sample:**

Download `input dataset <https://nextgis.com/data/toolbox/import_glr/import_glr_inputs.zip>`_ to test the instrument. Step-by-step instructions included.

Get the `output <https://nextgis.com/data/toolbox/import_glr/import_glr_outputs.zip>`_ to additionally check the results.
