Улучшение ЦМР
Улучшение разрешения ЦМР и упрощение соответствующих изолиний рельефа.


* Растровый файл
Выберите файл или перетащите в эту область
Растровый файл ЦМР, полученный при заказе NextGIS Data
* Метод интерполяции
Метод интерполяции, используемый для улучшения файла ЦМР. Доступные методы: nearest, bilinear, cubic, cubicspline, lanczos, average, rms, mode
* Шаг горизонталей
Шаг горизонталей векторного файла в метрах
* Шаг упрощения
Шаг упрощения горизонталей в векторном файле. Возможна запись в виде целого числа (например, 2), десятичной дроби через точку (например, 0.02) и экспоненциальная запись (например, 2e-2)
* Процент улучшения
Коэффициент улучшения разрешения растрового файла ЦМР, в %. Показывает, на сколько процентов должно увеличится/уменьшится размер пикселя. Например, значение 1000 % процентов даст уменьшение размера пикселя в 10 раз
