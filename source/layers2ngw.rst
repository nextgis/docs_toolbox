Векторные слои из архива в Веб ГИС
=====================================

На входе:

* Веб ГИС - Адрес вида https://sandbox.nextgis.com
* Логин
* Пароль
* ID группы ресурсов - номер, которым заканчивается адрес папки в строке браузера. Для Основной группы ресурсов ID=0
* ZIP-архив - архив с файлами GPKG, SHP или GeoJSON. Поддерживается загрузка QML с именем как у векторного файла. Поддерживаются вложенные папки
* Файл QML - QML файл, который будет приложен ко всем загруженным слоям. Должен быть подходящего типа геометрии.

На выходе:

* В Веб ГИС в указанной папке создаются векторные слои.

Запуск инструмента: https://toolbox.nextgis.com/t/layers2ngw

**Попробуйте инструмент в действии, скачав наш пример:**

`Набор исходных данных <https://nextgis.ru/data/toolbox/layers2ngw/layers2ngw_inputs_ru.zip>`_ для проверки работы инструмента. Внутри архива пошаговая инструкция.

`Пример результата <https://nextgis.ru/data/toolbox/layers2ngw/layers2ngw_outputs_ru.zip>`_ работы инструмента.
