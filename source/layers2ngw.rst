Векторные слои из архива в Веб ГИС
=====================================

Инструмент позволяет создать в Веб ГИС сразу много слоёв из набора файлов, загружаемого в виде ZIP-архива.


На входе:

* Веб ГИС - Адрес вида https://sandbox.nextgis.com
* Логин
* Пароль
* ID группы ресурсов - номер, которым заканчивается адрес папки в строке браузера. Для Основной группы ресурсов ID=0.
* ZIP-архив - архив с файлами GPKG, SHP или GeoJSON. Поддерживается загрузка QML с именем как у векторного файла. Архив может содержать в себе вложенные папки, но в Веб ГИС все слои будут в указанной группе ресурсов на одном уровне.
* Файл QML - QML файл, который будет приложен ко всем загруженным слоям. Должен быть подходящего типа геометрии.
* Опционально: Уведомить по электронное почте по окончании выполнения

На выходе:

* В Веб ГИС в указанной папке создаются векторные слои.

Запуск инструмента: https://toolbox.nextgis.com/t/layers2ngw

**Попробуйте инструмент в действии**

1. Нажмите кнопку **Демо** над формой инструмента. Поля будут автоматически заполнены демонстрационными значениями.
2. Нажмите кнопку **Запустить**.
