Calculate max distance between polygon nodes
============================================

Adds an attribute to each polygon showing maximum distance between nodes. Distances are measured in meters along the edges. Multipolygons are exploded. 

Input: 

* Single GeoJSON or GeoPackage file.

Output:

* GeoJSON or GeoPackage file with added field containing information about the maximum distance between nodes in each object.

Launch the tool: https://toolbox.nextgis.com/t/maxdist

**Try it out using our sample:**

Download `input dataset <https://nextgis.com/data/toolbox/maxdist/maxdist_inputs.zip>`_ to test the instrument. Step-by-step instructions included.

Get the `output <https://nextgis.com/data/toolbox/maxdist/maxdist_outputs.zip>`_ to additionally check the results.
