Копирование группы ресурсов Веб ГИС с данными
=============================================

.. warning:: По умолчанию инструмент стирает всё в целевой группе! Не выбирайте группу, где есть нужные файлы.

Копирование группы ресурсов nextgis.com в другой каталог или инстанс с данными. Так же копируются данные в слоях, вложенные каталоги, стили и веб-карты со ссылками на слои.  Копируются следующие типы ресурсов:

* группа ресурсов,
* векторный слой, 
* векторный стиль QGIS,
* веб-карта.

На входе:

* Адрес исходной Веб ГИС. Ссылка на исходную Веб ГИС на платформе NextGIS Web вида https://demo.nextgis.com и логин/пароль, если необходимо;
* Идентификатор исходной группы. Номер ресурса группы в исходной Веб ГИС;
* Адрес Веб ГИС назначения. Ссылка целевую Веб ГИС на платформе NextGIS Web вида https://demo.nextgis.com и логин/пароль, если необходимо. Если копируете внутри одной Веб ГИС, впишите те же данные, что для исходной;
* Идентификатор группы назначения. Номер ресурса группы в целевой Веб ГИС, где будет создана новая группа;
* Пропустить копирование данных. Создать пустые слои с полями и стилями.

На выходе:

* Группа ресурсов в целевой Веб ГИС

Запуск инструмента: https://toolbox.nextgis.com/t/ngw_copy_group
