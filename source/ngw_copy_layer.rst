Дублировать структуру векторного слоя nextgis.com
=================================================


   
Инструмент осуществляет дублирование структуры векторного слоя nextgis.com в другой каталог или другую Веб ГИС. Копируются названия полей, порядок полей, типы полей, псевдонимы и описания. Метаданные в текущей версии не копируются.

На входе:

* Адрес исходной Веб ГИС. Полный адрес Веб ГИС, например: https://sandbox.nextgis.com;
* Идентификатор исходного слоя. Номер ресурса слоя в исходной Веб ГИС;
* Исходный логин. Имя пользователя, имеющего права на чтение;
* Исходный пароль. Пароль пользователя Веб ГИС;
* Адрес целевой Веб ГИС. Полный адрес целевой Веб ГИС, например: https://sandbox.nextgis.com. Может быть тем же что URL исходной;
* Идентификатор группы назначения. Номер ресурса группы во второй Веб ГИС где будет создан слой;
* Логин целевой Веб ГИС. Имя пользователя, имеющего права на создание ресурсов в целевой Веб ГИС;
* Пароль целевой Веб ГИС. Пароль пользователя целевой Веб ГИС;
* Пропустить копирование данных. Создать только пустой слой с полями.

На выходе:

* Результатом является создание слоя в целевой Веб ГИС.

Данные копируются вместе с вложениями.

Запуск инструмента: https://toolbox.nextgis.com/t/ngw_copy_layer

**Попробуйте инструмент в действии**

1. Нажмите кнопку **Демо** над формой инструмента. Поля будут автоматически заполнены демонстрационными значениями.
2. Нажмите кнопку **Запустить**.
