Каталог учетных номеров
========================

Преобразует результаты поиска сервиса ПЛК в табличный вид.

Позволяет получить справочник по участку по его номеру в быстром локальном доступе в виде привычной таблицы.

На входе:

* Учетный номер - Учетный номер участкового лесничества, например 43:31:7
* Данные в DB формате - Отметьте, чтобы получить данные в формате базы данных. Если не отметить - данные будут выгружены в формате CSV

На выходе:

* Файл CSV или DB. Таблица содержит названия,учетные номера и номера по лесоустройству следующих атрибутов выделов - регион, лесничество, участковое лесничество, (урочище), квартал, выдел.
Если данные о выделах отсутствуют - на выходе таблица по кварталам.

Запуск инструмента: https://toolbox.nextgis.com/t/plk_catalog
