Каталог учетных номеров
========================

Преобразует результаты поиска сервиса Публичной лесной карты в табличный вид.

Позволяет сохранить представленную сервисом ПЛК информацию об учетных номерах кварталов и выделов в границах участкового лесничества в виде привычной таблицы.

.. figure:: _static/plk_catalog_gpkg_ru.png
   :name: plk_catalog_gpkg_pic
   :align: center
   :width: 20cm

   Результат работы инструмента на карте

.. important:: Инструмент не предназначен для массового извлечения данных. Не пытайтесь получить им все участки города или кварталы области.

На входе:

* Учетный номер - Учетный номер участкового лесничества, например 43:31:7
* Данные в DB формате - Отметьте, чтобы получить данные в формате базы данных SQLite. Если не отметить - данные будут выгружены в формате CSV
* Сведения о месторасположении - Отметьте, чтобы получить данные о месторасположении в формате GPKG

На выходе:

* Файл CSV. Таблица содержит названия,учетные номера и номера по лесоустройству следующих атрибутов выделов - регион, лесничество, участковое лесничество, (урочище), квартал, выдел. Если данные о выделах на сервисе ПЛК отсутствуют - на выходе таблица с учетными номерами кварталов.
* Файл GPKG

Источник данных: `ФГИС ЛК модуль "Публичная лесная карта" <https://pub.fgislk.gov.ru/map/>`_. Вся атрибутивная информация источника является публичной и общедоступной. Компания NextGIS не несет ответственности за состав данных источника.
