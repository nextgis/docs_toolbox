Каталог учетных номеров
========================

На входе:

* Учетный номер - Учетный номер участкового лесничества, например 43:31:7
* Данные в db формате - Отметьте, чтобы получить данные в формате базы данных

На выходе:

* Файл CSV или DB. Таблица содержит названия,учетные номера и номера по лесоустройству следующих атрибутов выделов - регион, лесничество, участковое лесничество, (урочище), квартал, выдел.
Если данные о выделах отсутствуют - на выходе таблица по кварталам.
