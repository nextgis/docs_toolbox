Генерация векторных тайлов из проекта QGIS
==========================================

Из архива с проектом QGIS и данными генерирует архив с векторными тайлами. Из проекта берутся только векторные слои, оформление не создаётся.

На входе:

* Архив с проектом и данными - ZIP-архив, содержащий проект QGIS и данные;
* Охват - Если охват пустой, то будет использован охват всех слоёв в проекте. Но он может неожиданно для вас охватить всю планету, тогда работа инструмента займёт очень много времени. Можно нарисовать на карте, нарисовать и подкорректировать полученные значения или ввести вручную в формате xmin, xmax, ymin, ymax в системе координат WGS 84 (EPSG:4326), например ``-7.3,42.1,10.5,50.5``;
* Минимальный уровень зума - от 0 до 25, по умолчанию 0;
* Максимальный уровень зума - от 0 до 25, по умолчанию 9.

На выходе:

* ZIP-архив, содержащий папки с тайлами в формате Protocolbuffer Binary Format (PBF), сгруппированными по уровням зума.

Запуск инструмента: https://toolbox.nextgis.com/t/qgis_vectortiles

**Попробуйте инструмент в действии, скачав наш пример:**

`Набор исходных данных <https://nextgis.ru/data/toolbox/qgis_vectortiles/qgis_vectortiles_inputs_ru.zip>`_ для проверки работы инструмента. Внутри архива пошаговая инструкция.

`Пример результата <https://nextgis.ru/data/toolbox/qgis_vectortiles/qgis_vectortiles_outputs_ru.zip>`_ работы инструмента.
