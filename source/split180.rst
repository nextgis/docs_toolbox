Разрезать геометрии по 180 меридиану 
=====================================

Чтобы объекты, пересекающие 180 меридиан, корректно отображались на веб-карте, их нужно специальным образом подготовить.
Разрезает геометрии объектов векторного слоя по 180 меридиану для дальнейшего отображения на веб-картах.
