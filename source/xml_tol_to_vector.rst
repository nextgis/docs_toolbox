Convert XML: TaxationDescriptionCuttingArea
===========================================

Convert XML: TaxationDescriptionCuttingArea to geodata.

Inputs:

* Source file. Single XML file or ZIP with any XML.
* Output format. One of output formats: GPKG, GEOJSON, SHP, TAB.

Outputs:

* ZIP archive with polygon and line layers in the chosen format.

Launch the tool: https://toolbox.nextgis.com/t/xml_tol_to_vector
